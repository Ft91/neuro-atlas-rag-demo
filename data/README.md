# Готовые данные учебной демонстрации

Разрешённые 20 статей и их исходные тексты, 49 поисковых документов/векторов, необходимые заголовки, связи и политики. Остальные статьи и полный DOCX отсутствуют.

Не переиндексируйте данные при первом запуске. Сохраните весь каталог. Проверка: `python -B -m tools.verify_demo` из корня проекта до настройки `.env`. Пользовательский кэш не включён и создаётся автоматически.

Проверенные контрольные суммы находятся в `../DATA_MANIFEST.json`. Владелец отдельно разрешил публичную публикацию включённых 20 статей. Полный атлас и остальные статьи публиковать запрещено.
