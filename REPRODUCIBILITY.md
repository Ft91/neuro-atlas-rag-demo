# Воспроизведение готовой демонстрации

Весь необходимый набор 20 статей и 49 поисковых документов уже находится в `data/`. Для проверки и запуска не требуется исходный DOCX, доступ к прежнему компьютеру или повторное создание эмбеддингов документов.

Сохраняйте структуру распакованной папки. Пути вычисляются относительно файлов проекта; ChromaDB открывается из `data/chroma_openai`, канонический SQLite — из `data/atlas.sqlite3`, FTS5 — из `data/atlas_search.sqlite3`. Коллекция определяется сохранённой версией индекса. Политики связей и пояснений относятся к этой же версии.

Установка и запуск описаны в README. Для офлайн-проверки используйте `tools.verify_demo` и `tools.test_demo`; ключи не нужны. Для реального Telegram понадобятся собственные API-ключ, баланс OpenAI, новый Telegram-токен и список разрешённых ID. Кэш будет создан локально пустым.

`DATA_MANIFEST.json` фиксирует побайтное совпадение перенесённых готовых файлов с разрешённым набором владельца на момент упаковки. `FILE_MANIFEST.json` фиксирует комплект поставки. Проверка проводилась в отдельной временной папке с запрещённой сетью; это проверка переносимости путей, а не испытание на всех версиях ОС и Python.

Не поставляются: полный DOCX, статьи вне выборки, `.env`, реальные токены/ключи, пользовательские диалоги, кэш ответов, журналы рабочего бота, окружение Python. Включённые контрольные вопросы — подготовленный тестовый набор, а не история пользователей.
